### How in the...!?!

Right now I just wanted to share it. Writing a full blog post explaining it all... not up for it today. Perhaps will replace this section someday.

Regardless, there's two pieces that work together.

First is the file parser [parse-lang-file](https://github.com/p-tupe/dotfiles/blob/main/scripts/.local/bin/parse-lang-file) - a rust script that splits an input file by language tags, sends each chunk to a TTS engine, then concats those chucks back into one audio file using [ffmpeg](https://ffmpeg.org/).

The TTS engine in question is [talk-it-out](https://github.com/p-tupe/talk-it-out) - I use [piper](https://github.com/OHF-Voice/piper1-gpl) for French and [kokoro](https://github.com/nazdridoy/kokoro-tts) for English (because I like the way each sounds, you can use one or the other only if you prefer). Hosted via server so each chunk does not load the whole binary on ram per run.

That's all you need. Cheers!
